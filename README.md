# Ayaan Digital

A React and TypeScript website for Ayaan Digital, presenting web, digital marketing, and AI service offerings.

## Run locally

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

The development server uses port 3000. For a production build:

```bash
npm run build
npm run start
```

The project also provides `npm run lint` for TypeScript checks. Review `.env.example` and configure any required keys locally before enabling server-side integrations. Do not commit secrets.

## Stack

React, TypeScript, Vite, and an Express server. See `package.json` for the current scripts and dependencies.
